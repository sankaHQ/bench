# drf-flask-002

Migrate to native Flask while preserving multipart uploads, file side effects, content negotiation and download headers.

This task deliberately reuses the pinned DRF source and scenario families from `drf-fastapi-009` to compare destination frameworks without changing source semantics. It adds target diversity; it is not an independent source application or a claim of greater source difficulty. The hidden evaluator still checks all edge cases and clean repeated state.
