# drf-flask-001

Migrate to native Flask while preserving order transitions, optimistic locking and transactional event records.

This task deliberately reuses the pinned DRF source and scenario families from `drf-fastapi-010` to compare destination frameworks without changing source semantics. It adds target diversity; it is not an independent source application or a claim of greater source difficulty. The hidden evaluator still checks all edge cases and clean repeated state.
